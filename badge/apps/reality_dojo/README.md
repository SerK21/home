# Time Dojo

Time Dojo is a time-themed fighting game for one or two badges.

## シミュレーター版の操作方法

Badge Simulator で `reality_dojo` を開きます。画面上のボタンをクリックするか、
矢印キーで上下左右、Space または Enter で決定できます。戻ると Home は
シミュレーター画面上のボタンを使えます。Esc は Home です。

| 操作 | 対戦中 |
| --- | --- |
| 左・右 | 移動 |
| 下 | ガード（長押し） |
| 決定 | 攻撃 |
| 上 | 必殺技（SP満タン時。実機ではバッジを振っても発動） |
| 戻る | メニューへ戻る |
| Home | アプリを終了してランチャーへ戻る |

上部の緑のバーは体力（HP）、青のバーは必殺技ゲージ（SP）です。
通常攻撃が当たると攻撃側は25、受けた側は15たまります。満タンで光ったら
上を押すか実機を振ると、SPを**全て消費**して強い攻撃を出せます。
空振りでもSPは消費します。
攻撃の直後は、次の攻撃まで少し待つ必要があります。ガード中は盾が現れ、
攻撃を防ぐと火花と「ガード!」が表示されます。
試合終了時は、勝つと `YOU WIN`、負けると `YOU LOSE` が表示されます。

## メニュー

- **CPU対戦**：CPUと１対１で対戦します。
- **キャラ作成**：上下で項目、左右で色・髪・顔・体型・国・力を選びます。
  決定で保存、戻るで変更を取り消します。力を上げると速度が下がります。
- **バッジ対戦**：２台のバッジで選び、近づけて接続します。
- **トーナメント**：自分とCPU７人による勝ち抜き戦です。３回勝つと優勝。
  CPU同士の試合は抽選で進行し、各試合のHPとSPは回復します。
  勝利後は決定で次の試合、戻るで終了します。負けると敗退です。
- **チュートリアル**：移動、ガード、通常攻撃でのSPチャージ、必殺技を練習します。
- **LANGUAGE**：日本語と英語を切り替えます。左右で選び、決定で保存、
  戻るで取り消します。設定はアプリを再起動しても維持されます。

試合前の操作説明画面では決定で開始、戻るで中止します。
国はG7各国とブラジルなどから選べます。国による能力補正はゲーム上の
小さな攻撃・速度のトレードオフであり、実際の国民性を表すものではありません。

## 時刻と通信

試合開始時の時計に応じて朝・昼・夕方・深夜の背景が変わり、深夜は攻撃力が
少し上がります。時計を取得できない場合は昼になり、画面に `?` が表示されます。
実機の時計は Clock アプリで設定します。

バッジ対戦はNFCではなく、近接ペアリングと無線通信を使います。
両方に同じバージョンのアプリと対応ファームウェアが必要です。旧版とは
ペアリングできません。ホスト側の時刻でステージが決まります。
シミュレーターでは無線対戦は利用できず、実機２台での対戦は未検証です。
Wi-Fiの認証情報は不要です。既存のキャラクター保存データは引き継がれます。

振り操作は加速度の強い変化を２回検知し、連続発動を抑えます。
シミュレーターでは上ボタンを使えます。振り判定の感度・誤爆防止は実機での
確認と調整が必要です。

日本語表示には [美咲ゴシック](https://littlelimit.net/misaki.htm) の
使用文字を同梱しています（ライセンスは `FONT-LICENSE.txt`）。

## Language settings

Select **LANGUAGE** from the main menu, choose 日本語 or ENGLISH with Left/Right,
then press Select to save or Back to cancel. The selection persists across restarts
and does not change your saved fighter.
